---
title: Datagen Source
---

The Datagen Source Connector provide a practical and efficient way to create synthetic data for testing. It acts as a data generator that creates artificial data based on the specific schema that you define.

## Compatible versions

| | |
|---|---|
| **External system** | None — events are generated inside Popsink |
| **Schema** | Avro schema you define on the connector |

<Note>There is nothing to version on your side: this connector has no external dependency.</Note>
