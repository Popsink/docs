Every version of the `oci://ghcr.io/popsink/charts/data-plane` Helm chart,
newest first, with the component versions each one installs. The table is
regenerated daily from the registry itself, so a version appears here as soon
as it is published.

<Warning>
This page is a history, not an upgrade target. The version a deployment should
run is the one the control plane reports for it — see
[Which version to run](/deployment/operate/upgrades#which-version-to-run).
</Warning>

- **Data plane**, **Broker (Tansu)** and **Kotatsu** are the image tags the
  chart's `values.yaml` sets by default (`image.tag`, `tansu.image.tag`,
  `kotatsu.image.tag`). **Kora chart** is the version of the bundled Kora
  sub-chart.
- A tag in **bold** changed since the previous chart version. Before moving the
  broker tag on an existing bucket, read the upgrade notes on `tansu.image.tag`
  in the chart's `values.yaml` — see [Upgrades](/deployment/operate/upgrades#kubernetes).
- A chart version links to its release notes, the list of changes it
  shipped. Notes are published weekly, so the newest versions may not have a
  link yet.
